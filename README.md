# Workforce Task Manager

ระบบมอบหมายและติดตามงานพนักงานผ่าน LINE บริษัท พุช มีเดีย จำกัด

- พนักงาน (LINE): https://liff.line.me/2011283911-17avazgG
- หน้าเว็บ: https://itsupport2-pixel.github.io/wtm-liff/

หน้าเว็บนี้เป็นไฟล์เดียว `index.html` (LIFF) ข้อมูลเก็บใน Google Sheet ผ่าน Apps Script (doPost)
ไฟล์ `careers-*` เป็นโลโก้และข้อมูลที่อยู่ที่ระบบใบสมัครงาน (pushmedia-careers) ดึงไปใช้ อย่าลบ
